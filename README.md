# 文件快转 · LAN File Quick Transfer

> 同一局域网内，PC / 手机 / 平板之间通过网页快速互传文件。
> 零安装、零残留、单文件约 6MB，启动即用。

## 简介

文件快转是一款基于 Go 的轻量局域网文件互传工具。无需安装客户端、无需登录、无需公网服务器——在同一 WiFi / 局域网内，任意设备打开浏览器即可互传文件。

前端页面通过 `go:embed` 内嵌进单个可执行文件，不依赖任何外部资源。

## 功能特性

- **实时广播**：发送端上传文件，接收端自动搜索并实时收到（WebSocket 实时推送）
- **点对点端口码**：发送端生成 4 位端口码，接收端输入端口码后私有接收，码到即用
- **多文件 / 文件夹**：支持批量上传与文件夹拖拽，下载时保留目录结构打包为 zip
- **多设备**：PC、手机、平板通用，响应式网页适配小屏
- **二维码扫码**：启动后在控制台打印二维码，手机扫码直达，免手动输地址
- **零残留**：下载后自动删除、24 小时兜底清理、退出清理、启动清空——即使强杀进程也不会残留临时文件
- **单文件**：前端全部内嵌，单个 exe 无任何外部依赖，可直接拷贝分享
- **大文件友好**：流式上传 / 下载，50MB 级文件秒级完成，内存占用稳定

## 快速开始（Windows）

1. 下载发布版 `文件快转.exe`
2. 双击运行（首次运行 Windows 防火墙可能弹窗，请选择“允许访问”）
3. 程序自动打开浏览器；手机连接同一 WiFi 后，用相机 / 浏览器扫一扫控制台或首页的二维码即可进入

> 非 Windows 用户可参照下方“开发者构建”自行编译本机版本。

## 使用方法

- **首页**：显示服务地址、二维码、当前在线设备数
- **发送文件**：进入发送页，可选择“实时发送”（所有接收端自动收到）或“点对点发送”（生成 4 位端口码，仅输入该码的接收端可收到）
- **接收文件**：进入接收页，可“自动接收”（实时广播）或输入端口码进行“点对点接收”
- **下载即删**：接收方下载完成后，服务端立即删除对应文件与批次

## 开发者构建

需要 Go 1.22+：

```bash
go mod tidy
go build -trimpath -ldflags "-s -w" -o 文件快转.exe .
```

如需在 Windows exe 中嵌入应用图标（`rsrc` 生成资源对象后自动被 Go 链接）：

```bash
go install github.com/akavel/rsrc@latest
rsrc -ico app.ico -arch amd64 -o rsrc_windows_amd64.syso
go build -trimpath -ldflags "-s -w" -o 文件快转.exe .
```

> 提示：`app.ico` 为任意 Windows 多尺寸图标文件（建议 16/32/48/64/128/256）；应用图标由 AI 辅助生成，可在 Release 附带的 exe 中直接查看效果。

## 存储与隐私

- 上传文件仅保存在程序目录下 `storage/` 临时文件夹，接收方下载成功后立即删除
- 未下载的文件会在 24 小时后被兜底清理；程序退出时清空；下次启动时再次清空——不产生任何残留
- 所有传输均在局域网内完成，不经过任何公网服务器
