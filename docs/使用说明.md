# 文件快转 · 使用说明

同一网络（同一 WiFi）下，在电脑、手机、平板之间快速互传文件的网页工具。

---

## 〇、轻量单文件版（推荐，用于日常使用与分享）

**`文件快转.exe`（仅约 6 MB）** 是重新用 Go 编写的单文件版，功能与完整版完全一致，但：

- ✅ **单文件即全部**：前端页面已内嵌进 exe，双击即可用，不依赖任何其他文件、不需要安装任何环境
- ✅ **体积仅约 6 MB**：不再需要 83MB 运行时 + 依赖包
- ✅ **可分享发布**：直接把 `文件快转.exe` 发给别人即可用（仅限 Windows 电脑）
- ✅ 所有功能不变：实时发送 / 4 位端口码点对点 / 拖拽上传 / 文件夹打包 / 二维码扫码 / 下载后自动删除 / 退出清理

**使用方式**：双击 `文件快转.exe` → 自动打开浏览器 + 控制台显示二维码 → 手机扫码或输入局域网地址即可。

> 说明：运行 exe 后会在 exe 同目录生成 `storage` 临时文件夹（存放传输中的文件，下载后/退出时自动清空，无需手动管理）。
> 若需移植到别的电脑，**只需要复制这一个 exe 文件**；Windows 首次运行若弹出防火墙提示，点「允许访问」。

## 一、如何启动（完整版备选）

如仍想使用工程目录内的完整版（源码方式），**双击 `启动.bat`**，会弹出一个黑色控制台窗口，同时**自动打开浏览器**进入工具页面。保持该窗口开启即可（关闭窗口 = 停止服务）。

> 提示：完整版已内置运行时（`runtime\node.exe`），无需安装任何软件即可运行。

## 二、如何访问

**手机访问（推荐，不用输地址）：**
- 电脑启动服务后，**控制台窗口里会直接显示一个二维码**，首页顶部也有同样的二维码
- 手机连接同一 WiFi 后，用**相机 / 微信扫一扫**即可直接打开工具页面，一次都不用输入地址
- 如果二维码失效（比如换了网络），刷新电脑首页即可看到新的二维码

电脑本机访问：启动后会自动打开浏览器；其他设备也可手动输入地址：

| 设备 | 地址 |
|---|---|
| 本机 | http://localhost:3000 |
| 手机 / 其他电脑（同一 WiFi） | http://192.168.1.4:3000 |

- 所有设备必须连接**同一个网络**（同一 WiFi / 同一路由器）

> **进阶：一劳永逸免输入** —— 如果家里的 WiFi 是固定的，可在路由器后台给这台电脑**绑定固定 IP**（DHCP 静态分配），绑定后局域网地址永不变；再用手机浏览器打开一次并「添加到主屏幕」，以后点手机桌面图标直达，连扫码都省了。

## 三、两种传输方式

### 方式一：实时发送（自动接收）

1. 发送端：打开网页 → **发送文件** → 实时发送 → 选择文件/文件夹 → 点击「发送给所有在线设备」
2. 接收端：打开网页 → **接收文件** → 自动接收，页面会自动列出收到的文件，点击「下载」即可

> 接收端打开页面即自动进入接收状态；发送端上传后，所有在线的接收端会**实时**收到提示。

### 方式二：点对点发送（4 位端口码）

1. 发送端：打开网页 → **发送文件** → 点对点发送 → 点击「生成端口码」，得到 4 位数字码
2. 发送端：选择文件 → 点击「上传到该端口码」
3. 接收端：打开网页 → **接收文件** → 点对点接收 → 输入对方的 4 位端口码 → 加入接收 → 下载文件

> 只有知道端口码的人才能看到和下载这些文件，适合私密传输。

## 四、支持的能力

- ✅ **电脑端支持拖拽上传**：在发送页直接把文件或文件夹拖进页面即可，无需点按钮
- ✅ 一次选择多个文件同时发送
- ✅ 选择整个文件夹发送（保留目录结构，接收端打包为 zip 下载）
- ✅ 大文件（几 GB 级视频、镜像等），流式传输不占内存
- ✅ 接收端下载后，文件自动从服务器删除（隐私、省空间）
- ✅ 未下载的文件 24 小时后自动清理（兜底）
- ✅ 停止服务时自动清理所有未下载的临时文件，保证不残留
- ✅ 手机 / 电脑均适配的响应式界面

## 五、常见问题

**1. 手机打不开网页？**
- 确认手机和电脑连接的是同一个 WiFi
- 首次运行时，Windows 防火墙会弹窗询问，请选择「允许访问」（专用网络/家庭网络都要勾选）
- 若仍不行，检查电脑与手机是否在同一网段（例如都是 192.168.1.x）

**2. 提示「端口已被占用」？**
- 服务会自动尝试 3000~3019 端口，通常不会冲突
- 如果都占用，请关闭占用程序后重试

**3. 手机浏览器不支持「选择文件夹」？**
- iOS Safari 不支持选择文件夹，请改用「选择文件」（可多选），或使用电脑浏览器选择文件夹

**4. 文件下载后在哪里？**
- 手机：浏览器默认下载目录
- 电脑：浏览器设置的下载目录

**5. 换网络后地址变了？**
- 局域网 IP 由路由器分配，可能变化；重启服务时控制台窗口会显示最新地址

## 六、注意事项

- 本工具仅限**同一局域网**内使用，不经过公网，文件不会上传到任何外部服务器
- 文件接收方下载后即从本机删除，请及时保存
- **停止服务时，会自动清理所有未下载的临时上传文件**（服务重启时也会先清空，保证不残留）；已下载到你设备上的文件不受影响
